# HD2-CNChat —— 绝地潜兵2 中文输入助手

一款面向《绝地潜兵 2》（HELLDIVERS 2）的**游戏内中文输入工具**，使用 AutoHotkey v2 编写。
不修改游戏文件、不读写游戏内存，仅通过模拟键盘输入实现，可随开随用。

> 实现方式参考了开源工具 GRW-CNChat：游戏内弹出**极简悬浮输入条**（仅输入框 + 关闭按钮），
> 中文用 **Unicode 编码（`{U+nnnn}`）** 模拟按键注入游戏聊天框。

---

## 原理

1. 游戏中按 **Enter**（与游戏聊天键一致）打开聊天框；
2. 工具检测到游戏窗口在前台，在窗口底部弹出一个**单行极简输入条**（系统输入法 IME 直接可用）；
3. 在输入条里正常输入中文，按 **Enter** 发送；
4. 工具把文本以 Unicode 编码模拟按键注入游戏聊天框并回车提交，输入条自动隐藏。

全程不需要切换窗口，不打断游戏操作。

## 功能

| 功能 | 说明 |
| --- | --- |
| 极简输入条 | 仅一个输入框 + 关闭按钮，默认停靠在游戏窗口**右下角偏上**，界面零干扰 |
| Unicode 发送（默认） | 逐字转 `{U+nnnn}` 用 SendEvent 注入，不依赖键盘布局，兼容性最好 |
| 5 种发送方式 | Unicode直发（默认）/ GBK Alt码 / 剪贴板粘贴 / PostMessage / ControlSendText |
| F9 切换方式 | 输入条中按 F9 循环切换发送方式，游戏内调试 |
| 修复乱码 | 发送 GBK Alt码 前自动把游戏线程输入法切换为中文、发完恢复 |
| 输入条定位 | 固定在游戏窗口**右侧居中**（距右缘 30px），跟随游戏窗口移动，位置不可手动调整 |
| 窗口匹配 | 进程名与窗口标题任一命中（标题包含匹配，`HELLDIVERS` 可命中 `HELLDIVERS™ 2`） |

## 使用

### 运行前提

- 安装 [AutoHotkey v2](https://www.autohotkey.com/)（≥ 2.0），双击 `HD2-CNChat.ahk` 即可运行；
- 或者用下方「编译为 EXE」一节生成免安装的单文件 exe；
- 系统需安装任意中文输入法（微软拼音、搜狗等均可）；
- 游戏中请使用**无边框窗口**或**窗口化**模式（全屏独占模式下无法显示悬浮输入条）。

### 首次使用

1. 启动工具即可——**游戏内按 Enter 直接可用，无需先点任何按钮**（「启动监听」为可选增强：开启后输入条跟随游戏窗口移动、状态提示等；默认关闭，可到设置改自动）；
2. 进入游戏，按 **Enter** 打开聊天 → 输入条出现在游戏窗口**右下角偏上**；
3. 直接输入中文，按 **Enter** 一次即发送（拼音合成中会自动提交并发送）；
   **Esc** 取消并关闭游戏聊天框（输入条失焦也会自动隐藏）。

### 快捷键

| 按键 | 作用 |
| --- | --- |
| Enter / 小键盘Enter | 游戏前台：打开输入条；输入条聚焦：发送（v3 模式：按键释放后比对文本，拼音提交后自动发送） |
| Ctrl+Enter | 备用通道：只要游戏进程存在即强制打开输入条 |
| Esc | 取消输入并关闭游戏聊天框（输入条失焦也会自动隐藏） |
| F9 | 循环切换发送方式 |

> 按键响应采用**双通道**：AHK 键盘钩子 + Windows 系统级热键（RegisterHotKey）。
> 即使其中一个通道被环境干扰，另一个仍能正常工作。
> v1.10 起 Enter 系统热键在启动时即常驻注册（不再依赖状态轮询），游戏内按 Enter 必定触发；
> 工具拦截后会自动补发按键（游戏内补发 Enter 打开游戏聊天框、桌面场景自动放行），不影响日常使用。

## 发送方式说明

| 方式 | 说明 | 适用性 |
| --- | --- | --- |
| Unicode直发（默认） | 逐字转 `{U+nnnn}` 用 SendEvent 注入 | 不依赖键盘布局，绝大多数游戏可用 |
| GBK Alt码 | 逐字转 GBK 编码，Alt+小键盘数字注入，配合「修复乱码」自动切换中文布局 | 需系统为中文区域 |
| 剪贴板粘贴 | Ctrl+C/Ctrl+V 原理 | 文字类输入框普遍可用 |
| PostMessage | 直接向游戏窗口发送 WM_CHAR | 部分游戏有效 |
| ControlSendText | 向窗口焦点控件发送文本 | 兜底方式 |

**调试流程**：发送后游戏内无反应或乱码时，按 **F9** 逐个切换方式尝试；
仍无效则在主面板勾选/取消「修复乱码」，或右键工具 → 属性 → 兼容性 → 勾选「以管理员身份运行」。

## 常见问题

**Q1：按 Enter 输入条没弹出来**
- 确认运行的是最新版本（面板标题版本号），先退出旧实例再启动；
- 游戏是「无边框窗口 / 窗口化」模式（全屏独占无法显示悬浮输入条）；
- 开启排障日志复现一次，把 `hd2cnc_debug.log` 发给开发者（日志会记录 Enter 触发与各环节状态）；

**Q2：发送后游戏里显示乱码 / 没反应**
按 F9 切换发送方式（默认 Unicode 直发兼容性最好）；
或尝试以管理员身份运行本工具（游戏以管理员权限运行时 SendInput 会被拦截）。

**Q3：输入条位置不合适**
输入条固定显示在游戏窗口**右侧居中**（距右缘 30px），并跟随游戏窗口移动；
如位置影响操作，可在「设置」中调整输入条宽度/字号。

**Q4：屏幕上方有状态提示觉得碍眼**
到「设置」里取消勾选「显示屏幕状态提示」（默认已关闭）。

## 配置与数据

- 配置文件 `HD2-CNChat.ini` 与脚本同目录（便携）；目录不可写时存到 `%APPDATA%\HD2-CNChat\`。
- 所有设置、发送历史、输入条位置均保存在配置文件中，删除即恢复默认。

## 编译为 EXE（可选）

1. 安装 AutoHotkey v2 时勾选 Ahk2Exe 编译器；
2. 双击运行 `build.ps1`（自动寻找 Ahk2Exe 编译，嵌入图标与版本信息）；
3. 生成的 `HD2-CNChat.exe` 可直接分发，无需安装 AutoHotkey。

## 自检模式（内部）

以参数 `selftest` 启动可执行内部功能自检（输入条创建、各发送方式、历史记录、
监听启停），结果写入 `selftest_result.txt`，用于排障。

## 诊断模式（排障用）

遇到问题时（如 Enter 无反应、发送失败），用以下任一方式开启诊断日志：

- **主面板「排障日志」按钮**：点击后变为「排障日志●」即已开启（再点关闭）；
- 或以参数 `debug` 启动：`AutoHotkey64.exe HD2-CNChat.ahk debug`。

开启后复现一次问题，把脚本目录下的 `hd2cnc_debug.log` 内容发给开发者。
日志会记录：热键注册/注销、Enter 触发时的监听状态、输入条状态、发送结果与失败原因。
