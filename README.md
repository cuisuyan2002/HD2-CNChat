# HD2-CNChat —— 绝地潜兵2 中文输入助手

一款面向《绝地潜兵 2》的**游戏外中文输入工具**，使用 AutoHotkey v2 编写。

> 实现方式参考了开源工具 GRW-CNChat

> [!IMPORTANT]
> **本项目已归档，不再维护。**
> 《绝地潜兵2》已于 **7.1.0** 版本支持中文输入，本项目原本要解决的问题已由官方实现，因此停止维护并归档。
