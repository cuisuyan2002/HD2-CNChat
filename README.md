# HD2-CNChat —— 绝地潜兵2 中文输入助手

一款面向《绝地潜兵 2》的**游戏外中文输入工具**，使用 AutoHotkey v2 编写。
不修改游戏文件、不读写游戏内存，仅通过模拟键盘输入实现。

> 实现方式参考了开源工具 GRW-CNChat：游戏内弹出**输入框**，
> 中文用 **Unicode 编码** 模拟按键注入游戏聊天框。

---

## 原理

1. 游戏中按 **Enter**（需与游戏聊天键一致）打开聊天框；
2. 工具检测到游戏窗口在前台，在窗口底部弹出一个**输入框**；
3. 在输入框里正常输入中文，按 **Enter** 发送；
4. 工具把文本以 Unicode 编码模拟按键注入游戏聊天框并回车提交，输入条自动隐藏。

全程不需要切换窗口，不打断游戏操作。

## 功能

| 功能 | 说明 |
| --- | --- |
| 输入条 | 默认停靠在游戏窗口**右侧居中** |
| Unicode 发送（默认） | 逐字转 `{U+nnnn}` 用 SendEvent 注入，不依赖键盘布局 |
| 5 种发送方式 | Unicode直发（默认）/ GBK Alt码 / 剪贴板粘贴 / PostMessage / ControlSendText |
| F9 切换方式 | 输入条中按 F9 循环切换发送方式，游戏内调试 |
| 输入条定位 | 固定在游戏窗口**右侧居中**，跟随游戏窗口移动，位置不可手动调整 |
| 窗口匹配 | 进程名与窗口标题任一命中（标题包含匹配，`HELLDIVERS` 可命中 `HELLDIVERS™ 2`） |

## 使用

### 运行前提

- 安装 [AutoHotkey v2](https://www.autohotkey.com/) ，双击 `HD2-CNChat.ahk` 即可运行；
- 系统需安装任意中文输入法
- 游戏中需使用**无边框窗口**或**窗口化**模式（全屏下无法显示输入框）。

### 首次使用

1. 启动工具即可——**游戏内按 Enter 直接可用，无需先点任何按钮**（「启动监听」为可选增强：开启后输入条跟随游戏窗口移动、状态提示等；默认关闭，可到设置改自动）；
2. 进入游戏，按 **Enter** 打开聊天 → 输入条出现在游戏窗口**右侧居中**；
3. 直接输入中文，按 **Enter** 即发送；中文输入法合成中按 Enter 只提交英文不发送（可继续输入），再按一次 Enter 才发送；
   **Esc** 取消并关闭游戏聊天框（输入条失焦也会自动隐藏）。

### 快捷键

| 按键 | 作用 |
| --- | --- |
| Enter | 游戏前台：打开输入条；输入条聚焦：发送|
| Ctrl+Enter | 备用通道：只要游戏进程存在即强制打开输入条 |
| Esc | 取消输入并关闭游戏聊天框（输入条失焦也会自动隐藏） |
| F9 | 循环切换发送方式 |

> 按键响应采用**双通道**：AHK 键盘钩子 + Windows 系统级热键。
> 即使其中一个通道被环境干扰，另一个仍能正常工作。
> 工具拦截后会自动补发按键，不影响日常使用。

## 发送方式说明

| 方式 | 说明 | 适用性 |
| --- | --- | --- |
| Unicode直发（默认） | 逐字转 `{U+nnnn}` 用 SendEvent 注入 | 不依赖键盘布局 |
| GBK Alt码 | 逐字转 GBK 编码，Alt+小键盘数字注入，配合「修复乱码」自动切换中文布局 | 需系统为中文区域 |
| 剪贴板粘贴 | Ctrl+C/Ctrl+V 原理 | 文字类输入框普遍可用 |
| PostMessage | 直接向游戏窗口发送 WM_CHAR | 部分游戏有效 |
| ControlSendText | 向窗口焦点控件发送文本 | 兜底方式 |

**调试流程**：发送后游戏内无反应或乱码时，按 **F9** 逐个切换方式尝试；
仍无效则在主面板勾选/取消「修复乱码」，或右键工具 → 属性 → 兼容性 → 勾选「以管理员身份运行」。

## 配置与数据

- 配置文件 `HD2-CNChat.ini` 与脚本同目录；目录不可写时存到 `%APPDATA%\HD2-CNChat\`。
- 所有设置、发送历史、输入条位置均保存在配置文件中，删除即恢复默认。
